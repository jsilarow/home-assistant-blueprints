## [1.0.0] – 2026-03-17

### Added
- Initial release of **home-assistant-blueprints** repository.
- **Motion Light + Sun Conditions** blueprint:
  - Motion-activated lighting with configurable no-motion timeout.
  - Optional sun conditions (sunset / sunrise with offsets).
  - Optional ambient light logic using IKEA VALLHORN (lux threshold).
  - Full documentation and import badge in `blueprints/motion_light_sun/README.md`.
